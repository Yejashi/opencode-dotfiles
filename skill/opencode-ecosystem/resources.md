# Guides, starters, and reference material

7 entries from the awesome-opencode registry, regenerated by
`~/.config/opencode/bin/skills-import-awesome`.

These are **third-party and unvetted** — the registry lists them, it does not
endorse or audit them. Treat an entry as a lead to go read the repo, never as a
recommendation to install. Verify anything before running it.


- **Akephalos** — A local-first, markdown-first `.akephalos` passport for portable agent preferences, tool notes, rules, project context, and durable memories. It uses plain files and Git so MCP-capable coding-agent workflows can inspect and carry context across tools and machines without hosted sync.
  https://github.com/sunnja69/akephalos
- **Coding Agent Orchestration** — An opinionated but practical handbook that argues for treating AI coding tools as a composable, multi-agent system rather than a single assistant, and then walks through how to implement that mindset using OpenCode's CLI, configuration system, and ecosystem (agents, tools, skills, and plugins).
  https://github.com/evermeer/CodingAgentOrchestration
- **Debug Log to Text File** — How to output a debug log from opencode to a text file for troubleshooting.
  https://github.com/awesome-opencode/awesome-opencode/discussions/19
- **GoTTY** — A simple command-line tool that turns your CLI tools, like opencode, into web applications.
  https://github.com/sorenisanerd/gotty
- **kickstart.opencode** — Inspired by kickstart.nvim. A minimal, well-commented OpenCode configuration designed as a starting point, not a framework. Every decision is explained. Includes free-only models and MCPs, a plan/execute workflow with interview-style clarification, and a careful agent for supervised AI execution. Read it, understand it, make it yours.
  https://github.com/orionpax1997/kickstart.opencode
- **Opencode Config Starter** — A powerful custom opencode configuration with agents, commands, rules, skills, and pre-configured MCP server.
  https://github.com/jjmartres/opencode
- **RunAPI MCP** — RunAPI MCP lets coding agents discover models, check pricing, and create image, video, music/audio, text-to-speech, and LLM tasks through RunAPI.
  https://github.com/runapi-ai/mcp
