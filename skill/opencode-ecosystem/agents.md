# Community agent and subagent packs

9 entries from the awesome-opencode registry, regenerated by
`~/.config/opencode/bin/skills-import-awesome`.

These are **third-party and unvetted** — the registry lists them, it does not
endorse or audit them. Treat an entry as a lead to go read the repo, never as a
recommendation to install. Verify anything before running it.


- **Agentic** — Modular AI agents and commands for structured software development with opencode.
  https://github.com/Cluster444/agentic
- **Claude Subagents** — Comprehensive reference repository for production-ready Claude Code subagents.
  https://github.com/VoltAgent/awesome-claude-code-subagents
- **deliberation** — Get a delegated second opinion or an actual fix from GPT (Codex), Gemini, Grok (xAI), or OpenRouter. Seven expert subagents - Architect, Plan Reviewer, Scope Analyst, Code Reviewer, Security Analyst, Researcher, and Debugger - plus the ask-gpt, ask-gemini, ask-grok, ask-openrouter, ask-all, and consensus commands. Each one can advise (read-only) or implement. ask-all asks every model at once and compares the answers; consensus runs an arbiter loop until the models agree.
  https://github.com/antonbabenko/deliberation
- **Gem Team** — Self-Learning Multi-agent orchestration harness for spec-driven development and automated verification.
  https://github.com/mubaidr/gem-team
- **NERV** — Spec-Driven Development pipeline, A2A task delegation hub, persistent semantic memory (MAGI), and 9 specialized subagents for OpenCode. Scaffolds 45+ files via `nerv init` including SDD skills, slash commands, MCP servers, and lifecycle plugins.
  https://github.com/juanmanueldaza/nerv
- **Opencode Agents** — A set of opencode configurations, prompts, agents, and plugins for enhanced development workflows.
  https://github.com/darrenhinde/opencode-agents
- **Python Expert Agent for OpenCode** — A custom configurable agent toolkit includes 1 Primary Custom Agent python-expert with intelligent skill loading, Predefined Specialized Subagents for Code generation, review, testing, and exploration, On-Demand Skills for Python development projects, Context Files for Standards, patterns, and security guidelines.
  https://github.com/amrahman90/python-expert-agent
- **Redstone** — an Opencode agent that simplifies Minecraft plugin development and deployment.
  https://github.com/BackGwa/Redstone
- **server-manager** — Start, track, and stop local dev servers in the background — without blocking your AI conversation. Supports Node.js, Python, Go, .NET, Java, Rust, PHP and any framework that runs a dev server. JSON state persistence, per-project log files, HTTP health checks, and log tail/grep for debugging.
  https://github.com/workdocyeye/server-manager
