# Community TUI themes

7 entries from the awesome-opencode registry, regenerated by
`~/.config/opencode/bin/skills-import-awesome`.

These are **third-party and unvetted** — the registry lists them, it does not
endorse or audit them. Treat an entry as a lead to go read the repo, never as a
recommendation to install. Verify anything before running it.


- **Ayu Dark** — Port of the popular Ayu Dark color scheme with golden yellow accent.
  https://github.com/postrednik/opencode-ayu-theme
- **Charcoal** — Charcoal is a pure grayscale theme for OpenCode with a near-black (#0d0d0d) background.
All 56 theme color keys use shades of gray — no hues anywhere. Designed to match a
minimal dark terminal aesthetic.

Also available for bat and Ghostty in the same repository.
  https://github.com/VyomJain6904/charcoal-theme
- **Lavi** — A soft, sweet dark theme for Opencode with rich purple tones and carefully tuned syntax and diff colors. Part of the Lavi colorscheme family, which also provides matching themes for Neovim, Alacritty, Ghostty, Kitty, Wezterm, Zellij, and other tools, with Nix flake and home-manager support.
  https://github.com/b0o/lavi/tree/main/contrib/opencode
- **Moonlight** — A moonlight color theme for OpenCode based on the popular moonlight-vscode-theme by atomiks. Features a dark, cool-toned palette inspired by moonlight aesthetics.
  https://github.com/brunogabriel/opencode-moonlight-theme
- **OpenCode Light Themes** — The largest collection of light themes for OpenCode. Includes 21 carefully crafted light themes converted from popular VS Code themes — scaefy-light (Atom One Light), Solarized Light, Vivid Light, Coffee Cream, GitHub Light, Quiet Light, Bluloco Light, Brackets Light Pro, NetBeans Light, Ysgrifennwr, Hop Light, GitHub Plus, Classic Light, HC Flurry, all Milkshake variants, and more. Bilingual (EN/TR) documentation and one-command install script included.
  https://github.com/fatihtoprakk/opencode-light-themes
- **Poimandres Theme** — Poimandres theme for opencode.
  https://github.com/ajaxdude/opencode-ai-poimandres-theme
- **VS Code Themes** — OpenCode ports of all built-in VS Code themes from the vscode.theme-defaults extension. Includes vscode-modern, vscode-plus, vscode-vs, and vscode-hc with automatic dark/light variant selection. One-line install script included.
  https://github.com/regen45t/opencode-vscode-themes
